# Pinned PAM packages for tests/detection/semantics/run.sh.
#
# Format (whitespace separated, one file per line):
#   <set> <pool file name> <sha256> <url> [<fallback url>...]
# <set> is a distro codename. run.sh looks for the file in its --cache
# directories first, then tries the URLs in order, and uses a file only if
# its SHA256 matches. The first URL is the official archive pool; the second
# is the official snapshot service, which keeps the exact file after the
# archive drops a superseded version.
#
# The packages are only unpacked (dpkg-deb -x and -e) and read or run from
# the unpack folder, without root. Nothing is installed.
#   libpam-runtime  pam-auth-update (a Perl script), its debconf templates
#                   and /usr/share/pam: all five releases
#   libpam-modules  pam_exec.so: four releases. Ubuntu 26.04's build needs
#                   glibc 2.43 and cannot load on the Ubuntu 24.04 image the
#                   suite runs on, so it is not listed.
#
# Every SHA256 below is the one in the archive's own index (Packages.xz,
# whose checksum is in InRelease) of the suite named in the comment. The
# InRelease signatures of the Ubuntu suites and of Debian's bookworm,
# bookworm-security and trixie-security were checked with gpgv; for
# trixie's own InRelease this machine had no key (UNVERIFIED signature:
# the debian-archive-keyring at hand is from 2023).
# To bump a version: download the new .deb from the pool, check it the same
# way, replace the file name, hash and both URLs, then run run.sh.
