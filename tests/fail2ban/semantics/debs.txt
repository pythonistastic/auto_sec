# Format (whitespace separated, one file per line):
#   <set> <pool file name> <sha256> <url> [<fallback url>...]
# <set> is a distro codename (jammy bookworm noble trixie resolute). run.sh
# tries the URLs in order and uses a file only if its SHA256 matches. The
# first URL is the official archive pool; the second is the official
# snapshot service, which keeps the exact file after the archive drops a
# superseded version.
#
# Every SHA256 below was checked against the signed archive index
# (InRelease -> Packages.xz) of the suite named in the comment.
# To bump a version: download the new .deb from the pool, check it the same
# way, replace the file name, hash and both URLs, then run run.sh.
